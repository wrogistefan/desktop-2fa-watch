# Security Policy

## Supported development version

Security work targets the latest development code. Version 0.2.0 is an MVP;
there is no separate long-term support branch or independent security audit.
See the [security model](docs/SECURITY.md) and [cryptographic design](docs/crypto.md).

## Reporting a vulnerability

Please report vulnerabilities privately to
[security@desktop-2fa.org](mailto:security@desktop-2fa.org), the security contact
used by the Desktop-2FA project. Identify **desktop-2fa-watch**, the app version
or commit, device/OS version, reproduction steps, and potential impact.

Do not include real vaults, passwords, or TOTP secrets. Use synthetic data when
providing examples. Please allow time for investigation before public disclosure.
No response-time guarantee is currently published.

Use [GitHub Issues](https://github.com/wrogistefan/desktop-2fa-watch/issues) for
ordinary bugs and feature requests, or
[contact@desktop-2fa.org](mailto:contact@desktop-2fa.org) for general questions.
